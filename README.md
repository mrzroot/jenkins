# Jenkins Pipeline Examples

A small collection of declarative Jenkins Pipeline examples written in Groovy.

## Included files
- Jenkinsfile: addition, division, and final-result stages.
- jenkinsfile123: the same pipeline with SCM polling.

## Run it
1. Create a Pipeline job in Jenkins.
2. Connect it to this repository.
3. Choose the Jenkinsfile to run.
