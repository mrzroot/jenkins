Run one in the simulator below, then in your own Jenkins.دو پایپ‌لاین declarative کوچک که در یک دقیقه خوانده می‌شوند: سه مرحله که مقداری را از طریق env به مرحلهٔ بعد می‌دهند، و همزادی که هر دو دقیقه گیت را بررسی می‌کند. اول در شبیه‌ساز پایین و بعد در جنکینز خودتان اجرایش کنید.

    env.SUM = sum.toString()
    Local def variables die with their stage. env survives across stages, but only stores strings, so convert back with toInteger().متغیرهای محلی def با پایان مرحله از بین می‌روند. env بین مراحل می‌ماند اما فقط رشته نگه می‌دارد؛ پس با toInteger() برگردانید.
    
      
    sum / 2
    Groovy's / on integers returns a BigDecimal: 8 / 2 is 4, 7 / 2 is 3.5. Use intdiv() for integer division./ در Groovy روی اعداد صحیح BigDecimal برمی‌گرداند: 8 / 2 می‌شود 4 و 7 / 2 می‌شود 3.5. برای تقسیم صحیح از intdiv() استفاده کنید.

    05FAQ
    
  
    Field notes.یادداشت‌های میدانی.
    
  
    Why does it store numbers in env as strings?چرا عددها را به‌صورت رشته در env ذخیره می‌کند؟
    Jenkins environment variables are always strings. The example shows the round trip: toString() when saving, toInteger() when reading in the next stage.متغیرهای محیطی جنکینز همیشه رشته‌اند. این مثال رفت‌وبرگشت را نشان می‌دهد: toString() هنگام ذخیره و toInteger() هنگام خواندن در مرحلهٔ بعد.
    
  
    Should I poll every 2 minutes in production?در پروداکشن هر ۲ دقیقه پول کنم؟
    Prefer a webhook from GitHub. If you must poll, use H/2 * * * *: the H spreads jobs across the interval so they don't all hit Git at once.وب‌هوک گیت‌هاب بهتر است. اگر مجبور به پولینگ هستید از H/2 * * * * استفاده کنید؛ H جاب‌ها را در بازه پخش می‌کند تا همه هم‌زمان به گیت فشار نیاورند.
    
  
    Do I need the script { } blocks?بلوک‌های script { } لازم‌اند؟
    For def, arithmetic and assigning env.X inside declarative steps, yes. For bigger logic, move it into a shared library or a function outside the pipeline block.برای def، محاسبات و مقداردهی env.X داخل stepsِ declarative، بله. منطق بزرگ‌تر را به یک shared library یا تابعی بیرون از بلوک pipeline ببرید.
    
  
    Can I use these files in my own projects?می‌توانم این فایل‌ها را در پروژه‌های خودم استفاده کنم؟
    Yes. The repository is MIT-licensed. Copy, adapt and ship.بله. مخزن مجوز MIT دارد؛ کپی کنید، تغییر دهید و استفاده کنید.
    
  
    Is the simulator running real Jenkins?شبیه‌ساز جنکینز واقعی اجرا می‌کند؟
    No. It replays Jenkins's console format in JavaScript, applying Groovy's division rules to your inputs. Nothing leaves your browser.نه. قالب کنسول جنکینز را با جاوااسکریپت بازپخش می‌کند و قواعد تقسیم Groovy را روی ورودی‌های شما اعمال می‌کند. چیزی از مرورگرتان خارج نمی‌شود.
